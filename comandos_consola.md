# Comandos usados

- pwd: para saber el directorio en el que me encuentro  
- ls: para ver el listado del repositorio  
- cd: para escoger la carpeta 
- mkdir: crear una carpeta
- ls -al: para conocer todo el listado  
- git config: para escribir en el archivo de configuracion  
- git config --global user.name "Nombre": para poner el nombre  
- git config --global user.email "Email": para poner el correo  
- git config list: para mirar y asegurarse del nombre y el registro
- git init: para comenzar el git 
- git rm -r "archivo"  
- touch: para crear archivo  
- vim "archivo": es un editor de codigo  
- git status: para conocer el estado del archivo  
- git add: para agregar el archivo a stage  
- git rm --cached archivo: para devolverme  
- git commit -m "Texto"
- git log: para ver todos los commits
